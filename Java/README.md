Password Validator - SafeLog 🔐
What is this project?
This is a simple Java program that checks if your password is strong and secure. It makes sure your password meets important security requirements before you save it.

How does it work?
The program asks you to create a password and then checks if it follows these rules:

✓ At least 8 characters long - Your password needs to be at least 8 letters/numbers/symbols
✓ Contains at least one UPPERCASE letter - Must have at least one capital letter (A-Z)
✓ Contains at least one number - Must have at least one digit (0-9)

If your password doesn't meet these rules, the program will tell you exactly what's missing and ask you to try again.

How to use it?
Compile the program:

javac PasswordValidator.java
Run the program:

java PasswordValidator
Follow the instructions:

The program will ask you to create a password
Type your password and press Enter
If it doesn't meet the requirements, you'll see an error message
Keep trying until your password is strong enough
Once accepted, it will say "Password created successfully!"

Why is this useful?
Strong passwords are important for keeping your accounts safe! This program helps ensure your password is:

Long enough to be hard to guess
Mixed with uppercase letters and numbers to make it stronger
